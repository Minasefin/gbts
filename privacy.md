# GBTS Privacy Policy

Last updated: November 23, 2026

GBTS (Getting Back to Success) is a personal tool used only by its owner, Mina. It has no other users.

## What data GBTS accesses

With the owner's permission, GBTS reads the owner's own Gmail account to find job alert emails, and may send emails the owner has set it up to send.

## How the data is used and stored

Email data is used only to run GBTS's job-search features for the owner, and is stored on the owner's own computer. Job details from those emails may be processed by an AI service (Anthropic's API) to score job matches and draft emails. Data is never sold or used for advertising.

GBTS's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

## Removing access

The owner can revoke GBTS's access at any time at https://myaccount.google.com/permissions
